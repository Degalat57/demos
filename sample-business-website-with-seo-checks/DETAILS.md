# Sample business website with SEO checks

## What this is
A four-page business website sample (Home, About, Services, Contact) with a page map, mobile-friendly HTML templates and an SEO audit. It was built from the public job post on synthetic data, not on client data.

## Done
- Page map rendered to static HTML templates with a responsive, mobile-friendly navigation
- WordPress WXR import file so the page map loads into a staging install
- sitemap.xml and robots.txt generated from the same page map
- SEO audit per page: title, meta description, viewport, indexing, canonical, heading order, image alt, links
- Contact form with required fields and a confirmation message
- Self-tests: all pages score 100, audit flags a broken page, sitemap and import match the page map

## Remaining
- Brand inputs: logo, colours and final copy
- WordPress theme build and plugin setup on the staging install
- Real contact form delivery and spam protection
- Domain, hosting and production deployment
- Full Lighthouse run on the live staging site

`python3 poc.py`
