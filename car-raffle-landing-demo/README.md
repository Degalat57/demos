# Car raffle landing page demo (sample data)

An offline, mobile-first concept raffle with illustrated vehicle slider, editable pricing, live countdown and simulated checkout.

**Live demo:** https://degalat57.github.io/demos/car-raffle-landing-demo/

## What it shows

- Original sample vehicle slider
- Bundle and flat pricing with local admin configuration
- Local simulated purchases, inventory and test-only checkout

## Data

synthetic sample data It is not real data about real people or businesses.

## How it was built

AI-assisted build: AI coding models wrote the code from a written spec, and automated checks (tests where present and a headless-browser render check) verified it before it was published. The code is plain, readable source with no build-time secrets.

## Run it locally

Open index.html directly, or serve this folder with python3 -m http.server 8000.
