# Property development site wireframe

## What this is
A clickable homepage wireframe with linked Location, Homes and Enquiry pages, showing a buyer journey for a property development site. It was built from the public job post on synthetic data, not on client data. It also produces a WordPress page plan and a lead-routing sample.

## Done
- Homepage wireframe with hero, two calls to action (book a viewing / request details) and journey cards
- Location, Homes (12 synthetic plots, "available only" filter) and Enquiry pages, all cross-linked, mobile layout
- Enquiry form: validation, intent/plot prefilled from links, demo routing message (nothing is sent)
- WordPress page tree, home-unit custom post type and form fields as JSON
- Lead validation and routing rules with sample CSV
- 6 automated checks (links resolve, every page reaches enquiry, counts computed two ways, rows preserved, routing)

## Remaining
- Branding, imagery, copy and plans from the production materials
- Building the WordPress theme/templates from the plan and installing on the GoDaddy hosting
- Real form delivery, agreed lead routing to the sales team, spam protection
- Choice of primary call to action: request details or book a viewing
- Accessibility and performance pass on the final pages
