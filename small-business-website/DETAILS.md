# Small-Business Website Template

A fast, accessible, SEO-ready static website for a local small business. No frameworks, no CDNs, no web fonts, no external images — just HTML, CSS, and a tiny bit of JavaScript, generated by a Python script.

The included sample brand is **Brightline Home Services**, a fictional home repair company in Springfield. Everything is a placeholder you can replace.

## Requirements

- Python 3.8 or newer (standard library only — nothing to install)

## Quick start

```bash
python3 build.py
```

This reads `site.json` and `templates/`, then writes a complete site to `dist/`. Open `dist/index.html` in a browser to preview.

To build **and** verify the output (links, headings, meta tags, accessibility basics):

```bash
python3 build.py --check
```

The check exits with code `1` and lists any problems it finds.

## How to rebrand (edit ONE file)

Open `site.json` and change the values. Then run `python3 build.py` again.

| Key | What it controls |
| --- | --- |
| `name` | Business name (header, footer, titles) |
| `tagline` | Home page headline |
| `description` | Default meta description and hero copy |
| `url` | Your live domain, used for canonical links and the sitemap |
| `phone`, `email` | Contact details everywhere |
| `address` | Street, city, region, postal, country (NAP + JSON-LD) |
| `hours` | Business hours in the footer and contact page |
| `primaryColor` | Main brand color (hex) |
| `accentColor` | Accent color for buttons and highlights (hex) |
| `formAction` | Where the contact form posts (see below) |
| `social` | Facebook, Instagram, LinkedIn URLs |
| `services` | Six service cards (title, summary, icon) |
| `testimonials` | Three customer quotes |
| `team` | Three team members |
| `posts` | Three blog articles |

**Colors:** set `primaryColor` and `accentColor` to any hex values. The build injects them into every page automatically.

**Icons:** each service uses one of `wrench`, `paint`, `bolt`, `drop`, `home`, `leaf`.

**Images:** there are none to replace. All artwork is inline SVG, so the site stays fast and needs no hosting for assets.

## Connect the contact form

The form works out of the box as a demo: it validates input and shows a message telling you to connect a backend. To make it live, set `formAction` in `site.json` to your form endpoint and rebuild.

- **Formspree:** create a form, then set `"formAction": "https://formspree.io/f/yourid"`
- **Netlify Forms:** add `netlify` and a `name` attribute to the `<form>` in `templates/contact.html`, then deploy to Netlify
- **Your own email:** use a service like Formspree or Basin that forwards to your inbox

## Deploy for free

The output in `dist/` is plain static files. Any static host works.

- **Netlify Drop:** go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag the `dist` folder in. Done.
- **GitHub Pages:** push the repo, then in Settings → Pages choose the branch and set the folder to `/dist` (or copy `dist` to `docs` and use that).
- **Cloudflare Pages:** connect your repo, set the build command to `python3 build.py` and the output directory to `dist`.

After deploying, update `url` in `site.json` to your real domain and rebuild so canonical links and the sitemap are correct.

## SEO checklist

1. Set `url` in `site.json` to your real domain and rebuild.
2. Submit `https://yourdomain.com/sitemap.xml` in [Google Search Console](https://search.google.com/search-console).
3. Create a free [Google Business Profile](https://www.google.com/business/) with the same name, address, and phone as `site.json` (NAP consistency matters).
4. Add your business to relevant local directories.
5. Ask happy customers for reviews — reviews are one of the strongest local ranking signals.
6. Keep the blog updated with genuinely useful articles for your customers.

Every page already includes a unique title, meta description, canonical link, Open Graph tags, and JSON-LD structured data (`HomeAndConstructionBusiness` on the home and contact pages, `FAQPage` on services, `Article` and `BreadcrumbList` on posts).

## How to add a blog post

Add an object to the `posts` array in `site.json`:

```json
{
  "slug": "my-new-article",
  "title": "My New Article",
  "date": "2025-01-15",
  "excerpt": "A one-sentence summary that appears on the blog index and in search results.",
  "body_html": "<p>Your article, written in simple HTML.</p><h2>A subheading</h2><p>More text.</p>"
}
```

Then run `python3 build.py`. The post page, blog card, sitemap entry, and structured data are all generated automatically. Use `<h2>` for section headings inside `body_html` (the page already has one `<h1>`).

## Project structure

```
site.json            # all content and branding
build.py             # the static site generator
templates/           # HTML templates
assets/css/style.css # stylesheet
assets/js/main.js    # menu + form validation
dist/                # generated output (do not edit by hand)
```

## Migrating from WordPress or Webflow

If you are moving from WordPress or Webflow, copy your existing page copy into the templates and your articles into the `posts` array in `site.json`. Keep your old URLs working by adding redirects at your host (Netlify `_redirects`, Cloudflare `_redirects`, or GitHub Pages via a redirect plugin). Point your domain at the new host once the content is in place, and resubmit your sitemap in Search Console.

## Accessibility notes

- Semantic landmarks, a skip link, and visible focus styles
- Mobile menu uses `aria-expanded` and `aria-controls`
- Form errors use `role="alert"` and `aria-invalid`
- All decorative SVG is hidden from assistive tech; meaningful SVG has `role="img"` and an `aria-label`
- Respects `prefers-reduced-motion`
- Print styles included
