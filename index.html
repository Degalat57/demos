Demos

Small, runnable web demos. Each was built with an AI-assisted workflow (AI coding models working from a written spec, verified by automated checks). Every name, record and number shown is synthetic sample data. Source for each demo is in its folder of this repository.

  • 5-Page Small-Business Website Template

    Fast, accessible, SEO-ready static site (home, about, services, contact, blog) rebranded from one JSON file.

  • Artist booking interactive prototype

    Browse fictional artists, choose a package and time, and inspect a simulated booking in customer, artist and admin views. No real payment or reservation.

  • Historic Burial Records Archive

    Searchable archive of historic ledger records: fuzzy name search, county/year filters, scan viewer, staff CSV import with validation.

  • Pharma Batch Review & Release — Process Intelligence demo

    Process mining, deterministic KPIs and an auditable copilot for pharmaceutical batch review and release: an SAP-style extract (order confirmations, goods receipts, inspection lots, results, deviations, usage decisions) becomes an event log with a data-quality report, outcome-to-process KPI drivers, an explainable maturity score, an intervention pre/post test and traced copilot answers.

  • Tea Steep Timer (Shopify section)

    Shopify OS 2.0 product-page section: water temperature, leaf amount and a calm countdown ring with re-steeps and a chime.

  • Tire Shop Digital Vehicle Inspection

    Phone/tablet web app for a tire and auto shop: jobs board, work orders, tire/brake/TPMS inspection with photos, and a customer report link.
