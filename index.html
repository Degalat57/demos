Demos

Small, runnable web demos. Each was built with an AI-assisted workflow (AI coding models working from a written spec, verified by automated checks). Every name, record and number shown is synthetic sample data. Source for each demo is in its folder of this repository.

  • 5-Page Small-Business Website Template

    Fast, accessible, SEO-ready static site (home, about, services, contact, blog) rebranded from one JSON file.

  • ABAP utilities demo: meter reading validation and billing estimate (tested on abaplint/transpiler)

    Synthetic ABAP source for utilities meter-reading validation and billing estimation, with 77 ABAP Unit methods executed on the open-source abaplint/transpiler stack (all ran without a failed assertion, 0 lint issues). No SAP system was used.

  • Artist booking interactive prototype

    Browse fictional artists, choose a package and time, and inspect a simulated booking in customer, artist and admin views. No real payment or reservation.

  • Car raffle landing page demo (sample data)

    An offline, mobile-first concept raffle with illustrated vehicle slider, editable pricing, live countdown and simulated checkout.

  • Historic Burial Records Archive

    Searchable archive of historic ledger records: fuzzy name search, county/year filters, scan viewer, staff CSV import with validation.

  • Pharma Batch Review & Release — Process Intelligence demo

    Process mining, deterministic KPIs and an auditable copilot for pharmaceutical batch review and release: an SAP-style extract (order confirmations, goods receipts, inspection lots, results, deviations, usage decisions) becomes an event log with a data-quality report, outcome-to-process KPI drivers, an explainable maturity score, an intervention pre/post test and traced copilot answers.

  • Property development site wireframe

    A clickable homepage wireframe with linked Location, Homes and Enquiry pages, showing a buyer journey for a property development site. It was built from the public job post on synthetic data, not on client data. It also produces a WordPress page plan and a lead-routing sample.

  • Sample business website with SEO checks

    A four-page business website sample (Home, About, Services, Contact) with a page map, mobile-friendly HTML templates and an SEO audit. It was built from the public job post on synthetic data, not on client data.

  • Tea Steep Timer (Shopify section)

    Shopify OS 2.0 product-page section: water temperature, leaf amount and a calm countdown ring with re-steeps and a chime.

  • Tire Shop Digital Vehicle Inspection

    Phone/tablet web app for a tire and auto shop: jobs board, work orders, tire/brake/TPMS inspection with photos, and a customer report link.

  • Web demo

    A minimal local Python web app: a form page sends input to a POST /api/process endpoint, which validates it and returns a JSON summary or structured JSON errors. It was built from the public job post on synthetic data, not on client data. It uses only the Python standard library (a Flask + Pydantic version is a direct port).

  • Web demo

  • Web demo

  • Web demo

It was built from the public job post on synthetic data, not on client data. It also writes the MVP user stories and a role permissions matrix.

  • Web demo
