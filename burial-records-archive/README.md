# Historic Burial Records Archive

A searchable public archive for historic burial-ledger records (1900-1965): visitors search transcribed details, open a record and view its scanned ledger page; staff add records from a CSV spreadsheet with validation and preview.

**Live demo:** https://degalat57.github.io/demos/burial-records-archive/

## What it shows

- Name search that also catches historic spelling variants (Johnson/Johnston, Mattie/Matty), county and death-year filters, sorting, shareable URLs and CSV export
- Record page with full transcription, a citation with copy button, and a scan viewer with zoom, rotate and pan
- Staff CSV import that flags missing fields, impossible dates, unknown counties and duplicate IDs before anything is added
- Static, fast and cheap to host; DETAILS.md notes how to scale to 100k+ records

## Data

All 200 records, names, places, counties, cemeteries and ledger scans are SYNTHETIC SAMPLES generated by `gen_records.py` (fixed seed); every record is marked "SYNTHETIC SAMPLE - not a real record". The counties and towns are fictional. It is not real data about real people or businesses.

## How it was built

AI-assisted build: AI coding models wrote the code from a written spec, and automated checks (tests where present and a headless-browser render check) verified it before it was published. The code is plain, readable source with no build-time secrets.

## Run it locally

```sh
python3 gen_records.py   # optional: regenerates data/ (deterministic)
python3 -m http.server 8000
# open http://localhost:8000/
```
