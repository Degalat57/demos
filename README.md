# Demos

Small, runnable web demos, each in its own folder with its own README. Built with an AI-assisted workflow: AI coding models wrote the code from a written spec, and automated checks verified it. All data in the demos is synthetic sample data.

| Demo | What it shows | Live |
|---|---|---|
| [5-Page Small-Business Website Template](small-business-website/) | Fast, accessible, SEO-ready static site (home, about, services, contact, blog) rebranded from one JSON file. | https://degalat57.github.io/demos/small-business-website/ |
| [ABAP utilities demo: meter reading validation and billing estimate (tested on abaplint/transpiler)](abap-utilities-demo/) | Synthetic ABAP source for utilities meter-reading validation and billing estimation, with 77 ABAP Unit methods executed on the open-source abaplint/transpiler stack (all ran without a failed assertion, 0 lint issues). No SAP system was used. | https://degalat57.github.io/demos/abap-utilities-demo/ |
| [Artist booking interactive prototype](artist-booking-prototype/) | Browse fictional artists, choose a package and time, and inspect a simulated booking in customer, artist and admin views. No real payment or reservation. | https://degalat57.github.io/demos/artist-booking-prototype/ |
| [Car raffle landing page demo (sample data)](car-raffle-landing-demo/) | An offline, mobile-first concept raffle with illustrated vehicle slider, editable pricing, live countdown and simulated checkout. | https://degalat57.github.io/demos/car-raffle-landing-demo/ |
| [Historic Burial Records Archive](burial-records-archive/) | Searchable archive of historic ledger records: fuzzy name search, county/year filters, scan viewer, staff CSV import with validation. | https://degalat57.github.io/demos/burial-records-archive/ |
| [Pharma Batch Review & Release — Process Intelligence demo](batch-release-process-intelligence/) | Process mining, deterministic KPIs and an auditable copilot for pharmaceutical batch review and release: an SAP-style extract (order confirmations, goods receipts, inspection lots, results, deviations, usage decisions) becomes an event log with a data-quality report, outcome-to-process KPI drivers, an explainable maturity score, an intervention pre/post test and traced copilot answers. | https://degalat57.github.io/demos/batch-release-process-intelligence/ |
| [Tea Steep Timer (Shopify section)](tea-steep-timer/) | Shopify OS 2.0 product-page section: water temperature, leaf amount and a calm countdown ring with re-steeps and a chime. | https://degalat57.github.io/demos/tea-steep-timer/ |
| [Tire Shop Digital Vehicle Inspection](tire-inspection-app/) | Phone/tablet web app for a tire and auto shop: jobs board, work orders, tire/brake/TPMS inspection with photos, and a customer report link. | https://degalat57.github.io/demos/tire-inspection-app/ |

Run any demo locally with a static file server (see its README). MIT licensed.
